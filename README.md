# sign-language-mediapipe

Experimenting with [Google MediaPipe](https://ai.google.dev/edge/mediapipe) to recognize sign language, starting with German Sign Language (DGS) and designed to extend to other sign languages.

## Goals

- Understand the ML pipeline end to end: data → features → training → evaluation.
- Learn what MediaPipe offers for hand/pose tracking.
- End with a clean, usable product.

## Status

Early exploration. No code yet.
